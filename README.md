# Finnish electricity market price control for Ecodan air-to-water heat pumps using CN105 port

This is yet another implementation for controlling Mitsubishi Electric Ecodan heat pumps using the CN105 port. It uses Finnish electricity price and weather forecast.

See for example the [ESPHome Ecodan heatpump project](https://github.com/gekkekoe/esphome-ecodan-hp) for a more feature rich implementation.

I have no need for WiFi or Bluetooth so I deciced to do a simpler implementation in Python. I currently run this on Raspberry Pi B+ 512 MB, communicating with Ecodan SUZ-SHWM60VAH with FTC6 controller board.

This uses a [Python implementation of the CN105 protocol](https://github.com/tatfri/ecodan_protocol) generated by Copilot based on protocol specification in the [ESPHome Ecodan heatpump project](https://github.com/gekkekoe/esphome-ecodan-hp/blob/main/protocol.md).

> [!CAUTION]
> Use at your own risk.
> This is an unofficial, unsupported implementation based on reverse-engineered Mitsubishi Electric protocol. [Melcloud](https://www.melcloud.com/) is the Mitsubishi Electric's officially supported commercial solution
> for remote control of compatible heat pumps.

## Theory of operation

This software controls indoor temperature setpoint and selects a time at which Domestic Hot Water (DHW) heating period is forced to start,
to minimize electricity cost required for heating.

Electricity market prices are fetched from https://porssisahko.net/api once in 24 hours. The algorithm does an estimation for energy cost
for the next 24 hours. If the estimated cost is below a set limit, temperature control is skipped to avoid fluctuations in indoor temperature.
The heating cost estimation is based on temperature forecast fetched from https://opendata.fmi.fi/wfs.

The algorithm finds the time intervals within the 24 hour period in which the electricity price is at the lowest 20% of the period, then the
lowest 40% etc. Temperature adjustment is then done around a set temperature middle point like this:

| Fraction | Temperature adjustment |
|----------|------------------------|
| 0% - 20% | +2 °C |
| 20% - 40% | +1 °C |
| 40% - 60% | 0 °C |
| 60% - 80% | -1 °C |
| 80% - 100% | -2 °C |

One forced DHW heating period is scheduled to be started when the electricity price is at the lowest point of the 24 hour period, for a period
long enough to get the tank heated, as configured.

The software then polls Ecodan for updated status, which is used for logging, and sets the temperature setpoint and triggers forced DHW heating,
until it is time to do another 24 hour estimation.

## Getting started

1. Review config.py and adjust settings as needed
2. Measure the pinout of heat pump's CN105 port and connect to UART of your device
3. Run test_comms.py to check that communication with the heat pump is working
4. Run main_loop.py
